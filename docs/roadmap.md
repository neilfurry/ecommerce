# Delivery roadmap

Approved on 2026-11-24. Rows 2 and 3 were delivered together as
Phase 2, and row 4 as Phase 3. Phase 4 delivered row 5, the customer storefront and search
(deferred from row 4), and the first part of row 9 (coupons and flash sales). Phase 5
delivered rows 6 and 7 together, plus seller payables and refund adjustments from row 8. Each
phase ends with a report in [docs/phases](phases/), and the next
phase starts only after the report is reviewed and approved.

| #   | Phase                               | Main deliverables                                                                                                                                                                                                                                                                              | Status                  |
| --- | ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------- |
| 1   | Foundation                          | Monorepo; Docker (PostgreSQL, Redis, MinIO, Mailpit); NestJS foundation with config, validation, errors, logging, health, Swagger, auth guards; Prisma conventions and migrations; 6 domain queues with retries and dead letters; storage abstraction; shared UI components; scripts; docs; CI | Done                    |
| 2   | Identity and access                 | Users, Argon2 hashing, access/refresh token rotation (HTTP-only cookies), configurable RBAC for all 14 roles, CSRF, audit log, sign-in in all apps                                                                                                                                             | Done (Phase 2)          |
| 3   | Sellers and stores                  | Seller onboarding and KYC status, admin approval, stores, seller staff, ownership guards                                                                                                                                                                                                       | Done (Phase 2)          |
| 4   | Catalog and inventory               | Categories, products, variants/SKUs, image upload, retail/wholesale/tier pricing, MOQ, stock ledger, reservations, search                                                                                                                                                                      | Done (Phase 3)          |
| 5   | Cart and multi-seller checkout      | Storefront, PostgreSQL search behind a provider interface, cart, addresses (PSGC), parent order with seller suborders, snapshots, checkout pricing service, idempotent checkout, mock shipping rates, coupons and flash sales                                                                  | Done (Phase 4)          |
| 6   | Payments                            | Provider adapters (GCash, Maya, cards, QR Ph, bank transfer, COD) with mocks, signed webhooks, reconciliation                                                                                                                                                                                  | **In review** (Phase 5) |
| 7   | Fulfillment and shipping            | Suborder status machine, shipping adapters, warehouse/delivery flows, cancellations, returns                                                                                                                                                                                                   | **In review** (Phase 5) |
